Digital Hardware Design

A collection of digital hardware design projects documenting my progression from fundamental digital logic to FSM-based control, simulation and verification, GTKWave waveform analysis, and embedded control systems.

Areas Covered

Combinational logic design
Sequential logic design
Finite State Machines (FSMs)
Verilog HDL
RTL simulation and verification
GTKWave waveform analysis
Embedded control systems
FPGA-oriented digital design

Purpose

This repository serves as a practical record of my digital hardware design learning process. Each project focuses on implementing a hardware concept, simulating its behavior, and verifying that the design operates as intended.

Project Structure

The projects are organized progressively, with each numbered directory representing a stage of the learning process.

Tools

Verilog HDL
RTL simulation
GTKWave
FPGA development tools

Verification Approach

Designs are verified through simulation and waveform analysis. GTKWave is used to inspect signals, state transitions, timing relationships, and the behavior of control logic during simulation.

Ongoing Development

This repository will continue to expand as I progress into more advanced RTL design, FPGA implementation, hardware verification, and embedded digital systems.
